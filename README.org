* [[https://theokrueger.dev][theokrueger.dev]]
my personal website

** deps
- install [[https://www.getzola.org/][zola]]
- install npm
- ~npm install~

** building
- ~npm run build~
- ~zola build~

** dev
- ~npm run build~ for updating static with transpiled+minified js
- ~npm run lint~ for linters
- ~zola serve~ for sitegen
